# Origem dos dados do banco

Os arquivos tabulares de suporte estão em `modulos/comunidade/data/` e `modulos/reabilitacao/data/`, evitando duplicação de grandes fontes oficiais. Os dados sintéticos de eventos são marcados como simulados. O SQL de schema/carga está em `banco-de-dados/sql/` e os diagramas editáveis em `banco-de-dados/diagramas/`.
