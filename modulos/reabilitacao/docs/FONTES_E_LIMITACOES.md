# Fontes e limitações

1. CNES estabelecimentos: https://dadosabertos.saude.gov.br/dataset/cnes-cadastro-nacional-de-estabelecimentos-de-saude
2. API oficial dados abertos do SUS: https://apidadosabertos.saude.gov.br/
3. Serviços especializados no ElastiCNES: https://wiki.saude.gov.br/cnes/index.php/Pain%C3%A9is_ElastiCNES
4. Rede de Cuidados à Pessoa com Deficiência: https://www.gov.br/saude/pt-br/assuntos/saude-de-a-a-z/s/saude-da-pessoa-com-deficiencia/rcpd
5. Modalidades CER: https://www.gov.br/saude/pt-br/assuntos/novo-pac-saude/selecao-2025/centros-especializados-em-reabilitacao

## Importante
- A lista de estabelecimentos CNES não comprova habilitação em modalidade nem acesso pelo SUS; o registro final precisa de conferência em fontes de serviços/habilitações e convênio SUS.
- CER tem modalidades físicas, auditivas, visuais e intelectuais. Reabilitação cognitiva não é categoria oficial autônoma de CER; exige orientação informativa e avaliação da rede local.
- CNES não fornece vagas em tempo real ou promessa de atendimento.
- Na versão 0.1, o arquivo `data/servicos_validados.csv` contém somente cabeçalho. Não há unidades importadas; isso é intencional. Nenhum dado fictício é exibido como serviço real.
- Para estatística da FIAP, baixar e tratar bases oficiais completas; não usar base simulada. Este protótipo ainda não contém dados suficientes para análise.
