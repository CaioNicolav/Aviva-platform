# IoT/AICSS

- **Implementado:** monitor local com entradas digitadas; não lê sensores.
- **Testado em simulação:** cenários e leituras manuais com variáveis/limites provisórios.
- **Evolução futura:** aguardando o PDF oficial de IoT/AICSS para definir requisitos, sensores, variáveis e critérios. Nenhum sensor é presumido ou integrado.
